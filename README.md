## 🎯 規格書說明 (Specifications)

### 一、 核心玩法與設計理念
1. **雙估值模型支援**：
   - **本益比法 (P/E Ratio)**：適用於成長型與一般獲利企業（合理價 = EPS × (1 + 預期成長率) × 目標本益比）。
   - **高登股利折現法 (Gordon DDM)**：適用於穩定配息之成熟企業（合理價 = 股利 × (1 + g) / (r - g)）。
2. **三段式合理價區間**：
   - 🟢 **便宜價 (安全邊際)**：合理價 × 0.85
   - 🔵 **合理估值**：模型計算結果
   - 🔴 **昂貴價 (風險區間)**：合理價 × 1.15
3. **即時互動視覺化**：
   - **滑桿與輸入框雙向連動**：數值調整即時反映，免重整頁面。
   - **估值光譜儀 (Spectrum Gauge)**：以動態指針精準標記目前市價所處區間。
   - **階梯柱狀圖 (Chart.js)**：直觀對比便宜價、合理價、昂貴價與目前市價。
   - **安全邊際與投資狀態燈號**：自動計算溢折價幅度並給出提示。
4. **預設經典股票**：
   - 內建台積電 (2330)、蘋果 (AAPL)、中華電 (2412)、可口可樂 (KO) 數據，一鍵帶入。

## 🛠️ 技術實作
- **架構**：單一檔案 `index.html`（CSS 與 JavaScript 全部內嵌）。
- **樣式庫**：Tailwind CSS (CDN)。
- **圖表庫**：Chart.js (CDN)。
- **無伺服器相依**：全純前端運算，任何現代瀏覽器均可直接開啟，並可 100% 部署於 GitHub Pages。
